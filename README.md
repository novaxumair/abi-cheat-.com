# ABI Cheats (abicheat.com)

Static Astro site for Arena Breakout Infinite cheats — Aimbot, ESP, wallhack, loot overlays — Cloudflare Workers ready.

Worldwide English SEO targeting **arena breakout infinite cheats**, **abi hacks**, and related PC keywords.

## Commands

- `npm run dev` — local dev server (port 5174)
- `npm run build` — generate OG assets, sitemap, Astro build, SEO verify
- `npm run preview` — preview production build

Set `SITE_URL=https://abicheat.com` when generating sitemaps for production.
